# Code of Conduct

KubeAmber follows the
[CNCF Code of Conduct](https://github.com/cncf/foundation/blob/main/code-of-conduct.md).

To report a violation, contact a maintainer listed in
[MAINTAINERS.md](MAINTAINERS.md) privately, for example by direct message on
GitHub. If the report concerns a maintainer, or you are not satisfied with
the response, you can escalate to the CNCF as described in the CNCF Code of
Conduct.
