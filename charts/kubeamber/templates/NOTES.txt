KubeAmber is installed in {{ .Release.Namespace }}.

1. Check that KubeAmber has started and is reviewing agents (should print the
   agent filter, not "false"; give it a few seconds after install):

   kubectl get validatingwebhookconfiguration kubeamber \
     -o jsonpath='{.webhooks[0].matchConditions[0].expression}'

2. Decide who may approve held changes:

   kubectl create clusterrolebinding kubeamber-approvers \
     --clusterrole=kubeamber-approver --group=<your on-call group>

3. Install the kubeamber CLI wherever people approve held changes:

   https://github.com/kubeamber/kubeamber/blob/main/docs/install.md#install-the-cli

4. Give each agent its own identity instead of your kubeconfig:

   kubeamber agent-kubeconfig claude-code --role edit --namespace dev
   KUBECONFIG=./claude-code.kubeconfig <your agent>

5. Review held changes:

   kubeamber list
   kubeamber approve <change request> --reason "..."
